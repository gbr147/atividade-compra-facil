# Compra Fácil

A **Compra Fácil** é uma Progressive Web App (PWA) de uma loja fictícia de jogos digitais.

O projeto foi desenvolvido como material didático para atividades de desenvolvimento de aplicações web e mobile, permitindo a realização de testes em computadores e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Worker
- Web App Manifest

## Executando o projeto

### 1. Clone o repositório

Clone este repositório para o seu computador:

```bash
git clone URL_DO_REPOSITORIO
```

Substitua `URL_DO_REPOSITORIO` pelo endereço deste repositório.

### 2. Acesse a pasta do projeto

```bash
cd compra-facil
```

### 3. Execute o projeto

Utilize um servidor local para executar a aplicação.

Se estiver utilizando o Visual Studio Code, você pode utilizar uma extensão como **Live Server**.

> A aplicação deve ser executada por meio de um servidor local. Não abra o arquivo `index.html` diretamente pelo sistema de arquivos.

## Testando em dispositivos móveis

A aplicação pode ser acessada em smartphones e tablets por meio de um servidor compatível com a rede local.

Também é possível utilizar as ferramentas de desenvolvedor do navegador para simular diferentes tamanhos de tela.

No Google Chrome:

1. Abra as ferramentas de desenvolvedor.
2. Ative o modo de dispositivo.
3. Selecione um dispositivo ou informe uma dimensão personalizada.
4. Teste a aplicação em diferentes larguras e orientações.

A aplicação também pode ser instalada como PWA em dispositivos compatíveis.

## Sobre o projeto

A Compra Fácil representa uma aplicação que está sendo preparada para publicação.

Durante o desenvolvimento, a equipe responsável deve realizar testes em diferentes dispositivos e verificar aspectos relacionados à experiência do usuário, responsividade e acessibilidade.

As alterações realizadas durante as atividades devem ser versionadas utilizando Git e enviadas para o repositório da equipe.

## Versionamento

Após realizar as alterações solicitadas nas atividades, utilize o Git para registrar e enviar suas modificações.

Exemplo:

```bash
git add .
git commit -m "descreva sua alteração"
git push origin main
```
